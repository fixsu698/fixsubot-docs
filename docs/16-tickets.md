# Tickety

**Kategoria:** `Zarządzanie`  
**Identyfikator:** `tickets`

---

> Zaawansowany system wsparcia dla społeczności. Pozwala na otwieranie prywatnych kanałów pomiędzy administracją a użytkownikiem.

### Konfiguracja

Możesz stworzyć wiele kategorii ticketów (np. Wsparcie, Zakupy, Skargi). Dla każdej kategorii wybierasz kanał powiadomień oraz rołę uprawnioną do odpowiadania.

- Generowanie pełnych transkryptów z rozmowy w formacie HTML.
- Panel z przyciskami (Buttons) lub menu wyboru.
- Limity otwartych ticketów na użytkownika.
