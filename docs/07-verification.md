# Weryfikacja (Vault)

**Kategoria:** `Bezpieczeństwo`  
**Identyfikator:** `verification`

---

> Pierwsza linia obrony przed botami i alt-kontami. Wymuś na nowych użytkownikach rozwiązanie Captchy lub kliknięcie odpowiedniego przycisku przed przyznaniem dostępu do serwera.

### Tryby Weryfikacji

Oferujemy kilka trybów bezpieczeństwa dopasowanych do Twoich potrzeb:

- Standard (Przycisk) - Najszybsza forma zabezpieczenia.
- Image Captcha - Bot generuje trudny dla maszyn obrazek z kodem.
- Web Vault - Użytkownik musi wejść na link, aby się zweryfikować (skuteczne przeciwko self-botom).
