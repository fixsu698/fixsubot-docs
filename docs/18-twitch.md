# Twitch Powiadomienia

**Kategoria:** `Social Media`  
**Identyfikator:** `twitch`

---

> Nie przegap żadnego streama! Bot automatycznie wyśle powiadomienie na wybrany kanał, gdy streamer uruchomi transmisję.

### Cechy

- Natychmiastowe pingowanie poprzez system EventSub.
- Możliwość zdefiniowania własnego komunikatu z pingiem roli (np. @Wszyscy).
- Automatyczne usuwanie ogłoszeń gdy stream dobiegnie końca (opcjonalnie).
