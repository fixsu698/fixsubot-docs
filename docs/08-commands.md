# Komendy (Slash)

**Kategoria:** `Zarządzanie`  
**Identyfikator:** `commands`

---

> Zarządzaj dostępem do komend slash (/) bezpośrednio z panelu. Włączaj, wyłączaj i ograniczaj użycie specyficznych komend.

### Access Control

Możesz zdefiniować role, które mają wyłączny dostęp do określonej kategorii komend (np. ogranicz użycie komend ekonomii tylko dla użytkowników VIP). Wszystkie komendy są natychmiast rejestrowane w Discord API po ich modyfikacji w panelu.
