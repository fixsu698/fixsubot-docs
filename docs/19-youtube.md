# YouTube Powiadomienia

**Kategoria:** `Social Media`  
**Identyfikator:** `youtube`

---

> Śledź swoich ulubionych twórców. Gdy opublikują nowy film lub krótkiego Shortsa, bot wrzuci link bezpośrednio na Discord.

### Działanie

W panelu podajesz ID kanału YouTube oraz kanał Discord do powiadomień. Bot korzysta z oficjalnego API (WebSub), co gwarantuje szybkość dostarczenia komunikatu w sekundy po publikacji materiału.
